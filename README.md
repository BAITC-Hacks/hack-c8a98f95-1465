# AlemEdu

Платформа образовательных задач: организации описывают проблему, студенческие команды предлагают решения, заказчик вручную выбирает исполнителей.

## Запуск backend

Нужны PHP 8.2+ и Composer 2:

```sh
cd backend
composer install
composer setup
composer dev
```

API: http://127.0.0.1:8000/api/health

Windows из корня репозитория: `powershell -NoProfile -ExecutionPolicy Bypass -File .\backend\start.ps1 -Port 18081`.

## Запуск frontend

В другом терминале, из корня репозитория. Нужен Node.js 22.12+:

```sh
cd frontend
npm ci
cp .env.example .env
npm run dev
```

В PowerShell используйте `Copy-Item .env.example .env`; при ограничении запуска npm.ps1 — `npm.cmd ci` и `npm.cmd run dev`.

Интерфейс: http://127.0.0.1:5173. Адрес API задаётся в `frontend/.env` через `VITE_API_URL` (по умолчанию `http://127.0.0.1:8000/api`). Если backend работает на 18081, поменяйте порт в этом адресе.

## Рабочий сценарий

1. Выберите демопрофиль заказчика, нажмите «Создать задачу», заполните название и описание.
2. Создайте черновик, ответьте на вопросы AI в полях карточки, подтвердите проверенные сведения и сохраните.
3. Посмотрите рейтинг и расшифровку, заполните организацию, регион и тему. Подтвердите публикацию и нажмите «Опубликовать задачу».
4. Найдите опубликованную задачу в каталоге поиском и фильтрами.
5. Откройте задачу, выберите профиль команды, заполните идею, план и сроки, отправьте отклик.
6. В «Моём кабинете» заказчик видит свои задачи, а команда — свои отклики и решения.

Рейтинг и его расшифровка приходят только из backend. Frontend не содержит формулу начисления баллов. AI на этом этапе — локальная заглушка из backend; интерфейс явно сообщает об этом. Демопрофили заменяют регистрацию только для демонстрации.

## Работа команды

1. `feature/backend-api` — данные, правила, API и демоданные.
2. `feature/vue-frontend` — интерфейс, каталог, редактор и отклики.
3. `feature/integration-demo` — интеграция и демонстрация.

Каждый следующий этап начинается с обновлённого `main`. Backend возвращает JSON с camelCase-полями; успешные ответы имеют оболочку `data`. Рейтинг и охват не блокируют опубликованные задачи.
