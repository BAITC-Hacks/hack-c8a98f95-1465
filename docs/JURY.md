# AlemEdu: памятка для жюри

**Сайт: https://minute-wifi-reserves-throughout.trycloudflare.com**

Установка и регистрация не нужны. Ссылка временная, работает пока компьютер организатора онлайн. Все профили и данные демонстрационные. AI на публичном показе явно работает в деморежиме; интеграция OpenAI готова и включается отдельно с ключом.

## Посмотреть за две минуты

1. Откройте «Каталог задач»: видны учреждение, регион, охват и готовность описания.
2. В меню выберите «Демо-заказчик 1», откройте «Мой кабинет».
3. Откройте отклики на «Расписание консультаций». Нажмите «Выбрать» или «Отклонить», обновите страницу: решение сохранено.
4. Переключитесь на соответствующую команду. В её кабинете видно решение заказчика.

Полный [показ до пяти минут](DEMO.md) включает создание задачи, публикацию с низким рейтингом и отклик команды другого учреждения.

## Если публичная ссылка недоступна

Организатор открывает проект и дважды нажимает `START.cmd`. Локальная версия: http://127.0.0.1:8080. На компьютере должны быть PHP 8.2+, Node.js 22.12+ и Composer для первой установки.

Или на любом компьютере с Docker из корня проекта: `docker compose up --build -d`, затем http://localhost:8080. Для автономного облачного адреса доступна кнопка Deploy to Render в [README](../README.md).
