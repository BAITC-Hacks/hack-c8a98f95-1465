# Размещение AlemEdu

Сборка объединяет Vue и Laravel: сайт `/`, API `/api`, файлы `/build/`. Все обращения браузера идут на тот же домен. CORS, два сервера и адрес backend для жюри настраивать не нужно. Прямые ссылки вроде `/tasks/2/offers` работают после обновления страницы.

## Уже опубликованное демо

https://minute-wifi-reserves-throughout.trycloudflare.com

Это [Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/), а не постоянный облачный сервер. Он работает, пока компьютер организатора, сервер на порту 8080 и cloudflared запущены. После перезапуска туннеля адрес изменится; обновите ссылку в README и памятке жюри. Не переводите компьютер в сон во время показа.

Для публичного показа сервер запускается с `start.ps1 -Demo`: отдельная база `.run/jury.sqlite`, отключённый debug и `AI_PROVIDER=mock`. Рабочая база `backend/database/database.sqlite` не используется. Туннель не открывает весь компьютер, только веб-сервер на 8080. Демопрофили доступны всем посетителям, поэтому вводите только синтетические данные.

Повторить временный показ в двух терминалах:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Demo
```

```powershell
& "$env:LOCALAPPDATA\AlemEdu\tools\cloudflared.exe" --no-autoupdate tunnel --protocol http2 --url http://127.0.0.1:8080
```

cloudflared на этом компьютере установлен из [официального источника](https://developers.cloudflare.com/tunnel/downloads/). Новый адрес выводится в терминале. `Ctrl+C` останавливает процесс в соответствующем терминале. Текущие запущенные в фоне процессы можно остановить в Диспетчере задач: cloudflared для ссылки, связанный PHP-сервер на 8080 для сайта. Не останавливайте другие PHP-процессы разработки.

## Docker: один запуск

Требуется только Docker Engine с Compose или Docker Desktop в режиме Linux containers.

```sh
docker compose up --build -d
```

Откройте http://localhost:8080. Первая сборка скачивает зависимости и образы, последующие используют кэш. Команды миграции и заполнения демоданных выполняются автоматически без удаления уже созданных записей. SQLite и ключ приложения сохраняются в volume `alemedu-data`.

```sh
docker compose ps
docker compose logs --tail 50 app
docker compose down
```

`down` останавливает приложение, сохраняя volume. **Не используйте `down -v` для обычной остановки:** это удаляет базу. Если порт занят, задайте `PORT=8085`; на PowerShell `$env:PORT='8085'`, затем команда запуска. API и сайт останутся на одном порту.

## Render: адрес, не зависящий от ноутбука

1. Нажмите [Deploy to Render](https://render.com/deploy?repo=https://github.com/BAITC-Hacks/hack-c8a98f95-1465), войдите в свой аккаунт и предоставьте доступ к репозиторию, если он закрытый.
2. Подтвердите Blueprint `render.yaml`. Выбран бесплатный демосервис, OpenAI-ключ не требуется.
3. Дождитесь статуса Live и откройте выданный HTTPS-адрес. Отдавайте жюри адрес сайта, не `/api/health`.
4. Перед показом откройте каталог и панель откликов. Проверьте, что нужные демопрофили загружаются.

На бесплатном тарифе SQLite эфемерна: после сна, рестарта или деплоя остаются только заново созданные исходные демоданные. Через 15 минут простоя сервис засыпает; пробуждение обычно занимает около минуты. Это ограничения [Render Free](https://render.com/docs/free), а не потеря данных внутри API. Не используйте этот режим для настоящих заказов.

Для постоянного сохранения выберите платный web service и подключите persistent disk на `/data`. У приложения уже настроен `DB_DATABASE=/data/database.sqlite`; дополнительно менять код не нужно. Изменения сохраняются только внутри подключённого диска, см. [Render Disks](https://render.com/docs/disks). Платные ресурсы создаёт и подтверждает владелец аккаунта самостоятельно.

## OpenAI и безопасность

Контейнер и публичная демоверсия по умолчанию используют `AI_PROVIDER=mock`, чтобы открытые демопрофили не расходовали API-ключ. Для реального AI сначала ограничьте доступ к показу настоящей авторизацией/защитой хостинга, затем задайте серверные `AI_PROVIDER=openai`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Никогда не добавляйте ключ в Dockerfile, Compose, Blueprint, образ или `VITE_*`.

Локальный `START.cmd` без флага `-Demo` сохраняет обычные настройки AI из `backend/.env`. [Подключение OpenAI](../backend/docs/AI.md).

## Проверки

GitHub Actions `Deployment check` собирает контейнер, проверяет сайт, API, статические файлы, прямые ссылки и сохранение ключа при рестарте. Frontend-тесты можно запускать против уже собранного отдельного демосервера:

```powershell
cd frontend
$env:E2E_BASE_URL='http://127.0.0.1:8080'
npm.cmd run test:e2e
```

Эти тесты создают задачи и меняют решения. Используйте только отдельную тестовую/демобазу, не сервер с реальными данными. Короткая проверка без изменения данных: `node scripts/check-deployment.mjs https://АДРЕС-САЙТА` из `frontend/`.
