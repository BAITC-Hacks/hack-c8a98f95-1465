# Показ AlemEdu: 4 минуты 45 секунд

## Подготовка

1. Откройте опубликованный сайт из [памятки жюри](JURY.md) либо запустите `START.cmd` и откройте http://127.0.0.1:8080/catalog. Два отдельных сервера нужны только для разработки.
2. Выберите «Демо-заказчик 1». Проверьте, что видна задача «Расписание консультаций» и её два отклика: `/tasks/2/offers` на адресе сайта.
3. Используйте обычный масштаб браузера. Панель проверяется на 1366×768 и 1920×1080; мобильный вариант на 390×844.
4. Оставьте эту инструкцию рядом. Запуск зависимостей и серверов не входит в пять минут.
5. Для настоящего AI заранее выполните `php artisan ai:configure` и `php artisan ai:check` из `backend/`, перезапустите backend. Проверка делает один платный запрос. Для автономного показа задайте `AI_PROVIDER=mock` и явно назовите это деморежимом.

## Текст задачи

- Название: «Разговорная практика первокурсников — демо».
- Организация: оставить университет «Алем» из выбранного профиля.
- Регион: Алматы.
- Тема: Языки.
- Охват: Учреждение.
- Описание: «Первокурсникам не хватает регулярной разговорной практики английского. Нужен простой тренажёр для занятий в парах».

После создания черновика покажите вопросы AI и отметку OpenAI с названием модели либо явную отметку деморежима. При необходимости дождитесь ответа до начала отсчёта демонстрации. Для демонстрации низкого рейтинга остальные содержательные поля оставьте пустыми. Подтвердите публикацию: задача появится в каталоге с 20 баллами.

## Текст отклика Qadam

- Идея: «Веб-тренажёр парных диалогов с короткими учебными сценариями».
- План: «Уточним ситуации общения, соберём прототип и проверим его с пятью студентами».
- Сроки: «Три недели».
- Ссылка на прототип: оставить пустой.

Qadam принадлежит демо-колледжу «Самғау», заказчик задачи — университету «Алем». Успешный отклик демонстрирует доступ команды другого учреждения.

## Повторный и запасной показ

Начинайте повторный показ с новой задачи, добавив номер к названию. Существующие решения можно пересмотреть кнопками «Выбрать» и «Отклонить». Не сбрасывайте основную базу ради показа.

Если времени мало, используйте готовую задачу №2 с двумя откликами и покажите каталог → отклики → решение → кабинет команды за две минуты.

При ошибке связи проверьте http://127.0.0.1:18081/api/health, затем `VITE_API_URL` и CORS по README. После восстановления используйте «Повторить» или заново отправьте решение; интерфейс не выдаёт сетевую ошибку за успешное сохранение.

## Что должно быть подтверждено

- Карточка показывает учреждение, регион, охват и готовность.
- Опубликованная задача с низким рейтингом видна в каталоге.
- Другая команда может откликнуться на задачу учреждения.
- Заказчик видит предложения, выбирает и отклоняет их вручную.
- Решения сохраняются после перезагрузки и видны команде.
