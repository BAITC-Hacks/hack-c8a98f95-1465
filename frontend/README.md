# AlemEdu Frontend

Vue 3, Vue Router, Vite, Axios и Lucide. Полная инструкция запуска обеих частей находится в [корневом README](../README.md), план показа в [DEMO.md](../docs/DEMO.md).

## Локальный запуск

Node.js 22.12+. Backend работает на `http://127.0.0.1:18081/api`.

```sh
npm ci
cp .env.example .env
npm run dev
```

Копирование окружения нужно только при первой настройке. На Windows: `Copy-Item .env.example .env`, `npm.cmd ci`, `npm.cmd run dev`.

Сайт: http://127.0.0.1:5173. Полный адрес API задаётся через `VITE_API_URL` в `.env`. После изменения перезапустите Vite.

## Экраны

| Маршрут | Содержимое |
| --- | --- |
| `/` | Главная и выбор роли |
| `/catalog` | Поиск, фильтры, учреждение, регион, охват, готовность |
| `/tasks/new` | Создание черновика |
| `/tasks/:id/edit` | Редактор, вопросы AI, подтверждение и публикация |
| `/tasks/:id` | Детали и отправка отклика |
| `/tasks/:id/offers` | Панель заказчика: список, фильтр решений, выбор и отклонение |
| `/workspace` | Свои задачи со счётчиками откликов или свои отклики с решениями |
| `/guide` | Справка |

## Решения заказчика

`GET /tasks/:id/offers` возвращает предложения с данными команды. `PATCH /offers/:id/decision` принимает `{ "decision": "selected" }` либо `{ "decision": "rejected" }`.

Frontend использует ответ API как источник статуса, блокирует повторные нажатия во время сохранения и сохраняет прежнее решение при ошибке. Смена профиля или задачи очищает приватный список; запоздавший ответ не попадает в другой профиль. Ошибку загрузки можно повторить, ошибку решения повторяют нажатием соответствующей кнопки.

Заказчик может выбрать несколько команд. Охват учреждения и рейтинг не ограничивают отклики. Баллы не пересчитываются во frontend. Карточка обновляет количество откликов после успешной отправки.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Playwright автоматически поднимает отдельный backend с демоданными и временной SQLite-базой: `18082` для API, `5174` для сайта. Основной проект на `5173/18081` можно оставить работающим. При установленном PHP вне PATH задайте полный путь в `E2E_PHP`.

Параметры тестирования:

| Переменная | Назначение |
| --- | --- |
| `E2E_PHP` | Путь к PHP для автоматического тестового backend |
| `E2E_PORT` | Порт тестового frontend, по умолчанию 5174 |
| `E2E_API_URL` | Использовать уже подготовленный отдельный API вместо автоматического запуска |

При внешнем `E2E_API_URL` тесты создают данные в указанной базе; используйте тестовый экземпляр и разрешите его frontend-origin в CORS. Конфигурация передаёт этот же адрес Vite автоматически. Занятый тестовый порт вызывает ошибку, а не подключение к случайному серверу.

Результаты и скриншоты находятся в `test-results/`, HTML-отчёт в `playwright-report/`. Проверяются весь путь до решения заказчика, нулевой рейтинг, доступ команды другого учреждения, несколько выбранных команд, отклонение, сетевые ошибки, смена профиля и адаптивность.

## Готовая сборка

`npm run build` создаёт `dist/`. Для локального просмотра выполните `npm run preview` и добавьте `http://127.0.0.1:4173` в `CORS_ALLOWED_ORIGINS` backend. `VITE_API_URL` встраивается при сборке; при смене API соберите frontend заново.

Для размещения настройте возврат `index.html` на маршрутах Vue Router, например `/tasks/2/offers`. Не размещайте секреты в переменных `VITE_*`. Демопрофили не заменяют производственную авторизацию.
