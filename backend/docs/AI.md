# Локальная AI-заглушка

Реализация: `app/Services/AiQuestions.php`. Внешних запросов, ключей и случайности нет. Одинаковый ввод даёт одинаковый ответ.

Алгоритм определяет тему по ключевым словам описания: язык, расписание, библиотека или общая задача. Он сохраняет исходное описание как `context`, принимает явно заполненные `fields` и определяет оставшиеся пустые поля. Для отсутствующих данных возвращается до семи вопросов; если пропусков меньше трёх, добавляются вопросы для проверки уже сообщённых сведений. Всегда минимум три вопроса.

`suggestedFields` содержит только исходное описание и непустые сведения из запроса. Уточняющие вопросы не превращаются в факты. Ничего не сохраняется и не публикуется автоматически. Пользователь отвечает на вопросы, редактирует карточку и явно подтверждает её.

## Ввод

```json
{
  "description": "Первокурсникам трудно практиковать разговорный английский.",
  "fields": {
    "users": "Первокурсники с уровнем A2."
  }
}
```

## Формат ответа

```json
{
  "data": {
    "mode": "mock",
    "topic": "language",
    "missingFields": ["materials", "constraints", "expectedOutcome", "successCriteria", "contact"],
    "questions": [
      {"id": "clarify_materials", "field": "materials", "question": "Какие данные, примеры и материалы доступны команде? Если их нет, укажите это."},
      {"id": "clarify_constraints", "field": "constraints", "question": "Какие есть ограничения по срокам, бюджету, технологиям и доступу?"},
      {"id": "clarify_expectedOutcome", "field": "expectedOutcome", "question": "Что именно команда должна передать в результате работы?"},
      {"id": "clarify_successCriteria", "field": "successCriteria", "question": "По каким измеримым признакам вы поймёте, что проблема решена?"},
      {"id": "clarify_contact", "field": "contact", "question": "Как связаться с заказчиком и в каком формате обсуждать работу?"}
    ],
    "suggestedFields": {
      "context": "Первокурсникам трудно практиковать разговорный английский.",
      "users": "Первокурсники с уровнем A2."
    },
    "notice": "Локальная заглушка. Ответы заполняет заказчик; автоматическая публикация и выдуманные факты исключены."
  }
}
```

## Пример промпта для будущего внешнего провайдера

> Ты помогаешь заказчику оформить образовательную задачу. Используй только данные description и fields. Верни JSON с missingFields, questions и suggestedFields. Задай минимум три относящихся к задаче уточняющих вопроса. У каждого вопроса должны быть id, field и question. Допустимые поля: context, users, materials, constraints, expectedOutcome, successCriteria, contact. Не придумывай организацию, сроки, бюджет, пользователей, контакты, материалы и критерии успеха. Не назначай команду и не публикуй задачу.

Этот промпт документирует ожидаемое поведение; заглушка не вызывает языковую модель.

## Ошибки

- Некорректный JSON запроса → HTTP 400, `message`.
- Пустое/слишком короткое описание, неверный тип или неизвестное поле → HTTP 422, `message` и `errors`.
- Нет действующего профиля заказчика → HTTP 401; роль команды → HTTP 403.
- Заглушка формирует ответ локально, поэтому ветки разбора ответа внешнего AI сейчас нет.

При подключении внешнего провайдера его ответ нужно проверять на структуру, допустимые поля и наличие минимум трёх вопросов. Если ответ некорректен, провайдер недоступен или истёк тайм-аут, адаптер должен вызвать существующую `AiQuestions::generate()` с исходным вводом. Непроверенный ответ нельзя сохранять в карточку. Это требование для будущей интеграции, не реализованное подключение.
